## 3. 坐标系、尺度与命名规范（UE5 对齐）

| 规范项 | 约定 |
|---|---|
| **Blender 单位** | Metric，Unit Scale = `1.0`，Length = `METERS`（1 单位 = 1 米；导出 FBX 时由 UE 预设自动换算厘米） |
| **坐标映射** | `island.json` 的 `(x_km, y_km, h_m)` → Blender `(X = x_km * 1000, Y = y_km * 1000, Z = h_m)`<br>`+X` 东、`+Y` 北、`+Z` 上（顶视图上北下南左西右东） |
| **光照方向** | 东南向晴日日光（晴日南崖受光）：方向向量 `(+0.54, -0.395, +0.743)`（指向光源），色彩管理 `AgX` |
| **对象命名（ASCII）** | 静态网格 `SM_<Name>`、材质 `M_<Name>`、贴图 `T_<Name>_BC/_N/_ORM`、空物体锚点 `LOC_<Name>`、相机 `CAM_<Name>`、灯光 `LGT_<Name>` |
| **集合层级** | `00_Anchors`（地标与预留建筑锚点，导出排除）<br>`01_Terrain`（主岛与东屿无缝地形）<br>`02_HeroRocks`（南剑峰、海蚀拱门、三座尖塔、海蚀柱、近岸礁石、外海浮标）<br>`03_Water`（大洋海面、镜湖、白水河、帘瀑）<br>`04_Vegetation`（云雾林树种原型与 GN 散射实例）<br>`05_Lighting_Cameras`（HDRI、日光、多角度验收相机） |
| **mat.bin 编码** | `0`=海底 / `1`=热带云雾林 / `2`=镜湖湿润湖滨草岸 / `3`=火山砾岸 / `4`=玄武岩绝壁与尖塔 / `5`=镜湖湖床 / `6`=水下暗礁盘 / `7`=黑砾湾白沙滩 |
